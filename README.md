# Does money buy happiness?

Scientific Data Visualization project by Fabio Anchisi, Gabriela Simon and Riccardo Gaglio.

Presentation: https://canva.link/tcii2mv33xsc8gt

### Contents
project/does-money-buy-happiness.ipynb: the code behind the slides
### Data 
project/WHR26_Data_Figure_2.1.xlsx: World Happiness Report, report years 2019 to 2024
World Bank indicators, one project/API_*.csv file each: GDP per capita (current US$), GDP per capita (PPP, constant 2021 int. $), population
### How to run
Install: pandas numpy matplotlib seaborn plotly scikit-learn geopandas country_converter openpyxl
Open the project/does-money-buy-happiness.ipynb file and run all cells from top to bottom.
The tables and figures are saved in a folder called outputs/.

Some plots (slides 5, 6, 7, 12, 13, 15) were redone in Flourish and slide 8 in Datawrapper. The notebook creates the data for them.
